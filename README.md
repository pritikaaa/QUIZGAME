# Quiz Game

An interactive and user-friendly **Quiz Game** built using HTML, CSS, and JavaScript. Test your knowledge, answer multiple-choice questions, and see your score at the end of the quiz.

##  Features

* 🧠 Multiple-choice quiz questions
* ⚡ Interactive question navigation
* ✅ Instant answer selection
* 📊 Score calculation
* 🔄 Option to restart the quiz
* 📱 Responsive and user-friendly interface
* 🎨 Clean and simple UI

##  Technologies Used

* **HTML5** – Structure of the quiz
* **CSS3** – Styling and responsive design
* **JavaScript** – Quiz logic, question handling, and score calculation

##  How to Run

### 1. Clone the repository

```bash
git clone https://github.com/pritikaaa/quizgame.git
```

### 2. Navigate to the project directory

```bash
cd quizgame
```

### 3. Open the project

Simply open `index.html` in your browser.

You can also use **Live Server** in VS Code for a better development experience.

##  How to Play

1. Start the quiz.
2. Read each question carefully.
3. Select the answer you think is correct.
4. Continue through all the questions.
5. View your final score.
6. Restart the quiz and try to improve your score!
